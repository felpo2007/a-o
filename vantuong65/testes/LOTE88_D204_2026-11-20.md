# Lote 88: um kit de som próprio para cada arma (D-204, 2026-11-20)

Uma sessão no Studio, numa cópia local do place (fora do repositório), com um jogador só (fuzileiro
dos EUA, M14). O medidor do cliente anotou cada som criado pelos kits (nome do trecho e grupo de
mixagem); o servidor anotou o trecho de cada pazada.
